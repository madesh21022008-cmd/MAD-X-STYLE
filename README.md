# MAD X STYLE - Luxury Streetwear Brand Landing Page

A modern, visually stunning premium clothing brand landing page featuring a dark luxury aesthetic with streetwear culture and contemporary minimalism.

## 🎨 Design Features

### Visual Aesthetic
- **Dark Luxury Theme**: Matte black background with charcoal gray accents
- **Premium Color Palette**: 
  - Matte Black (#0B0B0B)
  - Charcoal Gray (#161616)
  - Luxury Gold (#C9A96E)
  - Soft Gray text (#D4D4D4)
  - White (#FFFFFF)

### Typography
- **Headings**: Anton / Bebas Neue (bold, eye-catching)
- **Body**: Poppins / Inter (clean, modern, readable)

## 📋 Page Sections

1. **Header/Navbar** - Fixed transparent navbar with glassmorphism effect and smooth scroll behavior
2. **Hero Section** - Full-screen luxury banner with bold typography and dark overlay
3. **Collections** - Grid of luxury collection cards (Hoodies, Streetwear, Jackets, Baggies)
4. **New Arrivals** - Modern product grid with wishlist functionality and ratings
5. **Brand Statement** - Split layout with bold typography and animated counters
6. **Lookbook** - Instagram-style masonry gallery with hover effects
7. **Testimonials** - Customer reviews in glassmorphism cards
8. **Newsletter** - Email subscription with minimal luxury design
9. **Footer** - Brand info, links, and social media icons

## ✨ Interactive Features

- **Smooth Scrolling**: Elegant page navigation
- **Navbar Transparency**: Changes background on scroll
- **Wishlist Functionality**: Save favorite products (localStorage)
- **Animated Counters**: Number animations on scroll reveal
- **Hover Effects**: Zoom, glow, and color transitions
- **Image Scaling**: Smooth hover zoom on products and gallery
- **Mobile Menu**: Responsive hamburger navigation
- **Form Handling**: Newsletter subscription with feedback

## 🎯 Animations & Effects

- Glassmorphism backgrounds with backdrop blur
- Smooth fade-in animations on scroll
- Gold glow effects on hover
- Image zoom transitions
- Staggered card animations
- Parallax scrolling effect
- Luxury shadows and depth

## 📱 Responsive Design

Fully responsive layout that adapts beautifully to:
- Desktop (1400px+)
- Tablet (768px - 1399px)
- Mobile (below 768px)
- Extra Small devices (480px and below)

## 🚀 Getting Started

Simply open `index.html` in your browser. No build process or dependencies required!

### Files
- `index.html` - Complete HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality

## 🔧 Features

### Wishlist System
Store favorite products using browser localStorage:
```javascript
// Get wishlist
window.MAD_X_STYLE.getWishlist()

// Clear wishlist
window.MAD_X_STYLE.clearWishlist()
```

### Newsletter
Subscribe to updates with email validation and success feedback.

### Smooth Navigation
Click navbar links for smooth scroll to sections.
